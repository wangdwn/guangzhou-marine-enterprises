# 广州海洋企业/产业排名体系 · 设计理念与大纲（讨论稿 v2）

> 本版性质：v1（2026-11-18）的「落地化修订」。重点补齐三件事——榜单到动作的转化机制、发布治理前置、上线前回测。修订对照见附 A。
> 性质：讨论稿，供团队审议，只定方向、原则、机制与验收口径，不含具体权重与指标数值。
> 目的：以排名为杠杆，把「监测」升级为「引导」，把数据变成话语权，并把榜单变成招商与服务的生产工具。
> 日期：2026-11-20

---

## 一、设计方向（我们要做什么样的排名）

**一句话定位：不做「经营业绩排名」（那是统计局的活，且数据我们拿不到），做「海洋产业结构排名」——这是别人没有数据、没有视角的独家赛道。**

依托广海汇 7045 家在穗涉海企业（含产业链、资本档、涉海依存度、空间分布等结构标签），回答三个问题：

1. **各区**——哪个区的海洋产业底座更厚、更集中、更「深蓝」？
2. **各产业**——六大海洋产业链哪条更完整、更有活力、更缺什么？
3. **各企业**——哪些是广州海洋产业的「领军力量」？

→ 对应三个榜单：区域榜、产业榜、企业榜（第三部分）。每个榜单都对应一个可交付的工作产物（第四部分）。

---

## 二、设计原则（七条）

1. **结构为主、财务为辅。** 广海汇是结构/标签型数据，财务数据只覆盖 31 家上市公司。排名主干靠结构指标，财务只做上市企业的补充维度，不做全量财务排名。

2. **分赛道、不搞综合榜。** 船舶海工与海洋药物不可比。企业榜按产业链分赛道；产业榜改为「六链诊断卡」，同一套指标并列呈现，不合成跨链总分。

3. **「阈值 + 标签」为主、连续打分为辅。** 企业榜采用「达标入选」制；区域榜、产业榜采用「指标并列 + 分项排位」，不做加权总分——权重缺少数据校准依据，且最易引发争议。

4. **硬数据优先、可复核、分级防刷。** 指标按可刷性分级：行为类信号（中标、资质、参保、专利）可信度高；登记类信号（认缴注册资本、企业数量）易被虚增。登记类只作分档标签，不得单独构成入选门槛；入选须至少一项行为类佐证。

5. **有来源、有时点、有口径。** 每个数字能对上账。官方排名一旦错，比不排更伤信用。

6. **排完必有动作，且动作可度量。** 每个榜单发布前必须绑定产出物、使用方、触发条件与周期（第四部分），缺一不发布。

7. **先回测、后发布（新增）。** 任何阈值与指标上线前，须通过第六部分的回测；不通过则降级为参考标签或暂缓该榜。

## 三、三个榜单（修订后的思路）

### 榜单一：区域海洋产业榜（各区）

- **排什么**：广州 11 区海洋产业的「底座厚度 + 集中度 + 深蓝度」。
- **指标方向（并列呈现，不加权）**：
  - 涉海企业数量（各区分布）
  - 涉海资本分档分布（认缴口径，仅作规模参考）
  - 核心层（core）企业占比——「真涉海」密度
  - 涉海依存度 >50% 企业数——「深蓝」密度
  - 高质量密度：专精特新 / 高新 / 上市（以官方名单为准）
  - 行为类佐证密度（新增）：有中标记录或有资质的企业占比——识别「空壳式涉海」
- **方法**：分项排位、并列呈现，不出加权总分。区域集中度需全市基准，缺基准时只做区内相对比较。
- **产出物**：区级短板简报（区 × 产业链的强项与短板，附招商/培育方向）。
- **数据源**：广海汇（主干）+ 区海洋产值（年鉴/统计公报，仅南沙有明确数字 473 亿，其余区待补，只作参考锚点）。

### 榜单二：六大海洋产业链诊断卡（产业）

- **排什么**：海洋药物、海洋交通运输、船舶海工、海洋新能源、深海矿产、海洋旅游——每条链一张诊断卡：完整度、龙头、资质、活跃度、短板。
- **指标方向（六链同口径并列）**：
  - 链企业数量：广州在穗数 vs 全国 54977 家基准，给出广州占全国比重（新增，比单纯数量更有分析力）
  - 核心环节覆盖率（上中下游是否齐全）
  - 龙头压阵：A 档企业数，且须有行为类佐证
  - 资质密度（专精特新 / 高新占比）
  - 招投标活跃度（近期中标金额/频次，依赖实体匹配，见第六部分）
- **方法**：同一指标六链并列，各指标可给相对位次，但不合成总分、不称「活力排名」。核心产出是每链的缺口诊断。
- **产出物**：缺链环节清单 → 靶向招商目标库（全国同链、不在穗的企业）。
- **数据源**：广海汇产业链数据（主干）+ 招投标（已在采）+ 资质名单。

### 榜单三：海洋领军企业榜（企业）

- **排什么**：广州海洋产业「领军力量」，做入选名单，不做连续排名。
- **入选两道门**：
  - 资格门：涉海依存度 >50% ＋ 处于产业链核心环节 ＋ 存续在营
  - 佐证门：至少一项行为类佐证——上市 / 官方资质（专精特新、高新、单项冠军）/ 近期中标 / 参保规模（数据可得时）
- **梯次分层（龙头 / 骨干 / 潜力）**：由资本档（认缴，仅作分层）叠加资质标签决定，不再作为入选门槛（v1 的「资本档 ≥C」移入此处）。
- **遴选流程**：机器初筛 → 人工复核 → 内部会审 →（对外时）公示与异议 → 入库。年度复核，不再满足条件即退出。
- **附加标签（用于分层，不用于打分）**：上市、专精特新、高新技术、央企国企、招投标活跃。
- **产出物**：领军企业库（含联系人、对接状态、服务诉求）。
- **数据源**：广海汇（主干）+ 资质名单（免费）+ 招投标（已在采）+ 东方财富（上市公司财务，免费）+ 参保人数/专利（付费，视预算）。

## 四、从榜单到生产力：转化机制（新增）

每个榜单发布前必须填满下表；任一栏空缺，该榜不进入发布。

| 榜单 | 产出物 | 使用方 | 触发与动作 | 周期 |
|---|---|---|---|---|
| 区域榜 | 区级短板简报（区 × 产业链短板 + 招商/培育方向） | 各区海洋主管部门；内参 | 发布后纳入区级对接议程；短板项转为年度招商/培育任务 | 年度 |
| 产业榜 | 缺链环节清单 → 靶向招商目标库（全国同链、不在穗企业） | 招商部门 | 诊断出缺口环节即生成目标企业清单，分派跟进 | 半年 |
| 企业榜 | 领军企业库（含联系人、对接状态、服务诉求） | 招商 / 企业服务部门 | 新入选即进入主动对接队列，限时首次触达；诉求登记入库 | 季度增量，年度发布 |
| 数据闭环 | 标签纠错清单 | 广海汇数据维护 | 对接中发现的错标、失效、新增企业，回写标签 | 随对接持续 |

**漏斗验收口径（只定口径，数值由团队定）**：入库企业数 → 触达率 → 有效对接率 → 招商线索数 → 意向/落地转化；另计标签纠错数，衡量数据反哺监测的闭环质量。

**责任与节奏**：每个产出物指定「责任岗」与「使用方」（岗位待团队拍板，见第九部分）。更新节奏为季度增量、年度发布；每期标注版本号与数据时点。

## 五、发布口径与治理（由 v1 末位问题前置）

对企业做「入选」是官方背书，涉及公信力与合规风险，须先于指标设计确定。建议分三阶段：

- **阶段 0 · 内部试运行**：三榜均作内部工作库，不对外、不出企业级公开名单。企业榜在此阶段即可驱动招商。
- **阶段 1 · 对外发布聚合榜**：区域榜、产业榜只发聚合结果，无逐企业背书风险，挂院 / 市局口径。
- **阶段 2 · 企业榜对外公示**：须走完遴选流程，设异议渠道，经合规审核，并明确性质是「入选名单」而非「评级」。

口径等级决定话语权量级与数据纪律的严格度；对外数字须二次对账。具体口径由团队拍板（第九部分）。

## 六、上线前回测（Gate 0，新增）

五项回测全部通过，方可进入阶段 0。判据下限由团队定，此处只定检验内容与失败处置。

| 回测项 | 做什么 | 通过判据 | 不通过的处置 |
|---|---|---|---|
| ① 阈值命中 | 按现有标签跑企业榜三条资格条件，统计命中数及产业链 × 区分布 | 命中数落在「可运营区间」（够成榜、不泛滥，由对接能力反推）；每链样本足以成赛道 | 调整阈值；样本不足的链不单列 |
| ② 打标质量 | 海洋大类 83% 未打标，补打标后分层抽检 | 抽检准确率不低于团队设定下限 | 未达下限的标签不用于入选，只作参考 |
| ③ 可刷性 | 检验资本档与参保/中标/资质的一致性；统计「认缴高但无任何行为信号」企业占比 | 此类企业占比可控，且不进入入选名单 | 资本档降为纯分层标签，收紧佐证门 |
| ④ 实体消歧 | 招投标中标主体与广海汇企业匹配（有统一社会信用代码则优先，否则名称匹配 + 人工核） | 匹配率足以支撑「招投标活跃」指标 | 匹配不足则该指标降为参考，不入门槛 |
| ⑤ 资质口径 | 专精特新等以工信部/省市官方名单重新对齐（现 in_932056 仅 5 家 vs tag 33 家） | 与官方名单一致、可追溯 | 不一致则资质标签不上线 |

## 七、缺陷与缺口（诚实交代，供决策）

| 缺口 | 影响 | 应对 |
|---|---|---|
| 非上市企业财务数据拿不到（99.56% 企业营收/利润不公示） | 做不了「全量财务实力排名」 | 不做财务排名，只对 31 家上市公司补财务标签 |
| 海洋大类 83% 未打标（5835/7045） | 产业榜、企业榜的「赛道归属」不准 | 先补打标（AI 按主营分类 + 人工抽检），纳入回测② |
| 区级海洋产值零散滞后（仅南沙有明确数字） | 区域榜缺「产值」硬锚点 | 用「企业数量 + 行为类佐证」替代，产值作参考锚点 |
| 专精特新字段口径混乱（5 家 vs 33 家） | 资质标签失真 | 以工信部官方名单为准，重新对齐，纳入回测⑤ |
| 参保人数/专利需付费或反爬 | 员工规模、创新维度成本高 | 视预算决定；免费渠道先用招投标 + 资质 |
| 认缴注册资本可被虚增（新增） | 资本档若作门槛会诱导增资，榜单失真 | 资本档只作分层标签；入选须行为类佐证 |
| 招投标主体与企业库实体未打通（新增） | 「招投标活跃」指标不可靠 | 做主体匹配，纳入回测④ |
| 缺全市涉海/全部企业基准（新增） | 区域集中度无法比较 | 补全市基准；缺失时仅作区内相对比较 |

## 九、待团队拍板的五个问题

1. **排几个榜、先排哪个？** 建议：内部先做企业榜（数据最全、直接服务招商）；对外先发区域榜、产业榜的聚合结果，企业榜最后公示。
2. **指标口径与企业榜分层规则？** 区域榜、产业榜不设权重；企业榜只需定「佐证门」认哪几类行为信号，以及梯次规则。是否引入付费数据也在此定。
3. **发布口径与阶段时点？** 院内发布还是挂市局/市政府口径；三个阶段各自的时间点。
4. **责任岗与使用方？** 每个产出物由谁维护、谁使用、首次触达时限多长。
5. **回测判据下限？** 「可运营区间」「抽检准确率下限」等，由团队按对接能力与风险偏好设定。

## 附 B：本大纲的底层依据（三份前置研究）

1. 《海洋企业产业排名体系_前置研究_世界排名方法论与数据盘点.md》——世界五大类排名方法论拆解 + 广海汇数据盘点
2. 《海洋排名体系_公开数据可得性评估.md》——公开渠道逐渠道实测 + 贡献度判断
3. 结论一句话：排名主干（70%）靠广海汇结构数据，公开渠道补 20–30% 增量，非上市财务数据是结构性天花板。
