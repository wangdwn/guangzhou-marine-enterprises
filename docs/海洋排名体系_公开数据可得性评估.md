# 公开渠道数据可得性评估 · 排名数据贡献度

> 承接《海洋企业/产业排名体系前置研究》，回答：公开渠道能拿到多少数据，能为排名做多大贡献。
> 日期：2026-11-18

---

## 一、核心结论（先给判断）

**公开渠道的数据是「增量补充」，不是「雪中送炭」。**

- 排名体系的**主干（约 70%）**只能靠广海汇结构数据——企业数量、产业链覆盖、资本档、涉海依存度、空间分布。这些**公开渠道给不了**，是我们独家。
- 公开渠道能补的**增量维度（约 20–30%）**：资质名单、招投标活跃度、上市公司财务、参保人数、专利数、区级海洋产值。
- **结构性天花板**：非上市企业的营收/利润，公开渠道拿不到（企业年报「选择性公示」，99% 企业不公示），所以**「全量财务实力排名」做不了**。

---

## 二、逐渠道实测结论

| 公开渠道 | 能拿什么数据 | 覆盖 | 获取难度 | 贡献度 |
|---|---|---|---|---|
| **东方财富 API**（实测可用） | 上市公司：市值、PE、营收、利润 | 仅 31 家上市涉海企业（占 7045 家的 **0.44%**） | 免费、无需登录、可批量 | 低（覆盖太窄） |
| **国家企业信用信息公示系统** | 注册资本、成立时间、股东、**参保人数**（应当公示）、行政处罚 | 全量 | 免费但反爬+验证码；财务字段**选择性公示** | 中（参保人数可用，财务不可用） |
| **智慧芽/天眼查/羽山 API** | 专利数、商标、软著、融资、招投标 | 全量（付费） | **付费 API**（按次 ¥0.1–0.5） | 中（能做创新排名，但需预算） |
| **公共资源交易中心**（已在采） | 招投标中标金额 | 涉海企业 | 免费，7 通道之一已在跑 | 高（已有管线） |
| **工信部/省市公开名单** | 专精特新、单项冠军、高新、独角兽资质 | 全量 | 免费、权威、可直接下载 | **高（最值得补全）** |
| **统计年鉴/区统计公报** | 区级海洋产值 | 区级（非企业级） | 滞后 1–2 年，零散 | 中低（只有南沙有明确数字 473 亿） |

## 三、三个关键判断（带证据）

### 1. 财务数据是结构性缺口，公开渠道补不了

《企业信息公示暂行条例》第九条：企业年报的「从业人数、资产总额、负债总额、营业总收入、利润总额、净利润、纳税总额」——**第七项规定由企业选择是否向社会公示**。实践中绝大多数非上市企业选择不公示。

→ 后果：7045 家涉海企业里 7014 家（99.56%）非上市，营收/利润**拿不到**。只有 31 家上市公司能通过东方财富 API 免费拿到财务数据。

→ **「营收排名」「利润排名」只能排上市公司（31 家），做不了全量。这是排名体系设计的硬约束。**

### 2. 「参保人数」是员工规模的最佳免费代理，但成本高

社保信息中的「单位参保人数」**应当向社会公示**（海南版年报说明明确）。这是「员工规模」维度的合法免费来源。

但：国家企业信用信息公示系统有验证码反爬，7045 家逐个查工作量大，需批量采集工具（或走天眼查付费 API）。

### 3. 区级海洋产值零散，但南沙有锚点

公开报道能拿到：南沙区 2024 年海洋生产总值 **473 亿元**（占 GDP 20.6%，来源：南沙开发区管委会副主任王巍，2026-11-18 中国经济论坛致辞）；全市 2024 年海洋生产总值 **4979 亿元**（占全省 25%）。

→ 「各区海洋产值排名」能做出南沙的锚点，但其他区只有定性描述（黄埔/番禺/增城「多点支撑」），需从区统计公报补数，数据滞后且不完整。

## 四、对排名体系设计的影响（数据约束 → 设计约束）

| 排名维度 | 数据可行性 | 设计结论 |
|---|---|---|
| 区域（各区海洋产业） | 广海汇全 + 产值零散 | ✅ 可做「企业数量/资本/涉海密度」排名；❌ 做不了精确产值排名 |
| 产业类型（六大产业链） | 广海汇全 + 83% 待打标 | ✅ 可做（先补打标）；专利/资质可加创新维度 |
| 企业（领军企业榜单） | 结构全 + 财务仅上市 | ✅ 做「阈值+标签」制入选名单（涉海依存度+资本档+资质）；❌ 不做营收连续排名 |
| 创新（专利/研发） | 广海汇文本 + 付费 API | ⚠️ 可做但需预算（智慧芽/天眼查） |
| 成长（增速/融资） | 招投标已在采 + 融资付费 | ⚠️ 部分可做 |

---

## 五、综合回答：公开数据能为排名做多大贡献

**量化判断：公开渠道能为排名补充约 20–30% 的增量维度，但撑不起排名的「主干」。**

- **主干 70%**：广海汇结构数据（谁在哪条海洋产业链、资本什么档、涉海有多深、分布在哪个区）——这是排名的「骨架」，公开渠道给不了，独家。
- **增量 20–30%**：资质名单（免费易补全）、招投标（已在采）、上市公司财务（东方财富免费但仅 31 家）、参保人数（信用公示有但反爬）、专利（付费 API）。
- **天花板**：非上市企业财务（99.56% 企业），公开渠道结构性拿不到。

**给设计的落地建议**：
1. 排名体系**以广海汇结构数据为主干**，不追求财务实力排名（那是统计局的事，我们数据也拿不到）。
2. 公开渠道**优先补三个高性价比增量**：① 资质名单（工信部/省市，免费权威）；② 招投标活跃度（已有管线）；③ 上市公司财务（东方财富免费）。
3. 专利、参保人数**视预算决定**要不要上（付费 API，7045 家批量）。
